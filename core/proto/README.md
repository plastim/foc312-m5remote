# Generated FOC-Stim message code (the remote's copy)

Generated by nanopb 0.4.9.1 from the FOC-Stim protocol definitions (`firmware/proto/focstim/*.proto`, the same
definitions restim ships) with `remote.options`, which turns the text fields the remote reads (firmware branch and
comment, debug strings = the trip report, teleplot ids) into fixed buffers: nanopb cannot arm callbacks inside a
oneof, so the firmware build's callback fields would be dropped on decode. The wire format is identical.

Regenerate (the generator and its protoc come with the firmware's PlatformIO environment):

    ~/tools/pio-venv/Scripts/python.exe firmware/.pio/libdeps/focstim_v4/Nanopb/generator/nanopb_generator.py \
        -I firmware/proto/focstim -D remote/core/proto -f remote/core/proto/remote.options \
        firmware/proto/focstim/constants.proto firmware/proto/focstim/messages.proto \
        firmware/proto/focstim/notifications.proto firmware/proto/focstim/focstim_rpc.proto

(It warns that each option "did not match" because it checks the file per .proto; check the generated structs.)
